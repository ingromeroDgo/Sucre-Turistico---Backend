# Plataforma-web-Full-Stack---Golfo-de-Morrosquillo
Basada en arquitectura de microservicios, que permita la promoción, consulta y gestión de la información turística del Golfo de Morrosquillo, facilitando a los turistas el acceso a datos actualizados sobre destinos, alojamiento, gastronomía, experiencias y eventos, y brindando a los administradores herramientas eficientes para su gestión
